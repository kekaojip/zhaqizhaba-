# INPUT ADAPTER

## 目的

把用户随手给出的自然语言，压成 Writer 当前真正需要知道的最小信息。

这是内部适配，不要求用户补表格。

## 只提取这些

- 当前 POV，若能判断；
- 当前地点与时间，若用户给了；
- 谁在场；
- 人物眼下想做什么；
- 当前压力或异常；
- 必须发生的事件；
- 明确不能新增或不能提前揭露的内容；
- 已有正文的最后状态；
- 用户指定的停点、长度、语体；
- 用户提供的参考正文。

其余上游方法论词全部忽略。

## 输入不足时

不要因为缺一两个字段停下来问表格式问题。

如果用户的目标很明确，例如“给我写个小片段看看”，允许补最少的信息让场景成立。

最小补全可以包括：

- 一个普通地点；
- 一个当前动作；
- 一个能推动两三拍的即时目的；
- 一个不影响长线设定的小阻力。

不要擅自补：

- 大型世界观；
- 复杂金手指规则；
- 长线反派；
- 重量级身世；
- 章节外重大剧情。

## 自动模式判断

### CONTINUE

有连续正文 + 继续/往下写。

重点保留：

- 前文最后动作；
- 当前人物口气；
- 已经公开的信息；
- 当前未完成动作。

### REWRITE

有原正文 + 重写/改自然/改好看。

默认锁定：

- 事实；
- 因果；
- 人物关系；
- 结果；
- 视角。

只重新选择正文语言。

### SCENE / CHAPTER

有明确事件链。

不要把每一条 bullet 一一翻译成一个段落。先还原成连续现场，再写。

### FREEWRITE

只有松散想法。

先形成一个很小的“现在”，再开始正文。

## 不把策划词带进正文

例如用户写：

- 这里要爽；
- 制造压迫感；
- 展现主角聪明；
- 提升节奏；
- 制造信息差。

内部转换成事实：

- 谁被谁压；
- 什么事情变难；
- 主角具体先发现什么；
- 哪个动作产生结果；
- 谁知道、谁不知道什么。

正文里不要出现这些策划术语。

## Genre 与语体分离

题材标签只帮助理解世界。

除非用户明确要求，默认正文语体：

`自然现代中文白话`

修仙不自动文言，古代背景也不自动“心下、眸光、已然、旋即”成片出现。
