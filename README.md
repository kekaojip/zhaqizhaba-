# zhaqizhaba-

Personal collection of reusable AI skills and utilities.

## Structure

- `video/` — video download, transcription, summarization, and analysis skills
- `research/` — research and web analysis skills
- `writing/` — writing-related skills
- `automation/` — automation helpers
- `utilities/` — general-purpose tools

Third-party skills are kept as close to upstream as possible, with their original license and provenance retained alongside the copied files.
