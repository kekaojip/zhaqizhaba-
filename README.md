# zhaqizhaba-

Personal collection of reusable AI skills and utilities.

## Structure

- `video/` — video download, transcription, summarization, and analysis skills
- `novel-prose-writer-zh/` — standalone Chinese fiction prose generation skill
- `research/` — research and web analysis skills
- `writing/` — other writing-related skills
- `automation/` — automation helpers
- `utilities/` — general-purpose tools

## Standalone novel prose writer

`novel-prose-writer-zh/` is intentionally self-contained. It accepts loose natural-language fiction requests, scene notes, chapter beats, prior prose, or rewrite requests and outputs novel prose without depending on the user's Main workflow, Writer Runtime, Human Writing L2, Tracking, or project files.

Third-party skills are kept as close to upstream as possible, with their original license and provenance retained alongside the copied files.
